# Job Portal

A full-stack Job Portal web application built using the MERN stack. It allows students to search and apply for jobs while recruiters can post and manage job listings.

---

## Features

### Student

- User Registration & Login
- Google Authentication
- Update Profile
- Browse Jobs
- Search & Filter Jobs
- Save Jobs
- Apply for Jobs
- View Applied Jobs

### Recruiter

- Recruiter Login
- Google Authentication
- Create Company
- Update Company
- Delete Company
- View Companies
- Post Jobs
- Update Jobs
- Delete Jobs
- View Job Listings
- View Applicants
- View Applications

---

## Installation

### Clone Repository

```bash
git clone https://github.com/paldhaduk7-png/Job-Portal.git
```

### Install Frontend

```bash
cd frontend
npm install
npm run dev
```

### Install Backend

```bash
cd backend
npm install
npm start
```
